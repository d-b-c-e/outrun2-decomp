# Session screen comparison

Shift+F7 during active driving cycles **Original game view**, **Angle correction**, then **Angle + curve** when the developer compositor is ready with a positive admitted curve radius. The first press selects Original. If Curve is unavailable, it is skipped and the short centered notice explains whether the developer compositor is disabled, pending/refused, or using a zero radius. This is a developer comparison and is never saved.

Original uses the existing Screens=Off rendering/presentation path inside the current window, including its fitted center viewport. Angle uses the configured Angled correction without the compositor. Curve uses the admitted developer curve source/compositor. The window, monitor topology, owner settings and saved screen mode are unchanged. The selected logical camera, fitted bumper/bonnet placement, smoothing, saved Game/Realistic framing and pose offsets stay the same throughout: this compares screen correction, not camera placement. Original therefore includes the independent native-port camera enhancements.

Opening F6, leaving active driving (including pause), changing camera, changing camera settings, or a curve-session refusal ends comparison and restores the normal configured rendering context. Plain F7 first ends comparison and retains its usual per-camera Game/Realistic saved toggle. Focus loss prevents a held F7 from firing on a synthetic release. Either Shift is supported, including Shift arriving before F7 or remaining held after F7 releases. While camera shortcuts are registered, Shift alone is a modifier and does not request wheel-to-keyboard handover. Raw Shift is never cleared and still reaches native input when the keyboard already owns driving; an ordinary driving key still requests handover.

The comparison switches effective projection globals at the game-thread input boundary, publishes a profile revision, and resizes only the offscreen scene target at the next renderer frame boundary. The original native video width is retained separately from the normal span width. Geometry shaders are cleared when leaving the three-view path; Original does not attempt to revalidate curve resources against its single-view target. Returning to the span recreates the distinct curve copy source before use. Resource/session refusal remains independent from the temporary comparison selection.

Validation is offline only. CPU controller and actual shim/native keyboard/H-pattern fixtures exercise the input consumer and persistence boundaries; a Desktop compile covers presentation/backend integration. GPU transitions, presentation fit, visible notice, seams, depth/HUD, MSAA/FXAA, reflections, performance and physical/owner acceptance require a later admitted rig run. No game, window, GPU/backend or device is initialized by these checks.

# Curve compositor shader and atlas sampling contract

`curve_compositor_shader.hpp` supplies the packed32-byte per-panel pixel constants and actual VS/PS source for the native16-byte XY/UV mesh. The vertex shader emits local clip XY with Z=0/W=1 and passes the mesh's already top-left D3D UV unchanged. The pixel shader remaps local source UV into one of three equal horizontal source images, clamps to that image's first/last texel centers, and samples RGBA without added gamma/alpha/color processing. It requires a linear/clamp sampler and a separate source image from the destination.

`curve_sample_rect` accepts equal-panel atlas widths divisible by3, at least2 source pixels per panel and2 rows, within the current backend's16384 dimension guard. It prepares uvMap at byte0 and uvLimits at byte16; failed dimensions/panel index leave output unchanged. Half-texel limits are rounded inward by one float step so packed bounds stay inside the chosen source image. This prevents the CPU sampling reference from reaching adjacent atlas panels at exact mesh-edge UVs. The shader adds no second V flip or extra pixel-center offset. Actual GPU size/capability checks remain the allocation owner's responsibility.

The standalone fixture passes **228,664 layout/atlas/pixel-reference/refusal checks**. It checks mesh POSITION float2 offset0 and TEXCOORD float2 offset8/stride16, pixel constants32/offsets0/16, per-panel bounds, all horizontal pixel centers at top/middle/bottom rows for6x2 through16383x16384 atlases (including7680x1440), and edge/outside-local-UV clamping without mathematical bilinear taps across source panels. Flat pixel-center coordinate error stays below.004 pixel with packed floats; this is not bit-identical rendered output or a GPU filtering bound. Invalid size/index controls retain prior constants.

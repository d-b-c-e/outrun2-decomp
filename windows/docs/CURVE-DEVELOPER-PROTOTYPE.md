# Default-off developer curve source and compositor

This connects the prepared native curve/source/mesh/shader contracts to the actual desktop D3D11 draw path. It is compiled and CPU-qualified only. No game/backend/GPU/device initialization, runtime mode enable, owner installation, rendered or physical acceptance occurred in this work.

The prototype also requires the existing normal borderless Angled/span admission. Latched tests, recording, playback and render-test sessions do not receive it. ## Source and lifetime

The window prepares one immutable process-lifetime profile: real-eye curve warps,64x36 per-panel mesh, original-panel inner rectangles and the existing shader/atlas sampling contract. A neutral borrowed view supplies3 contiguous16-byte XY/UV vertex regions (2405 vertices each),13824 shared uint16 indices,32-byte per-panel sampling constants and the HLSL. The backend validates the layout before creating resources. No simulation or control tick is repeated.

The actual native projection determines a virtual source eye, preserving the selected camera framing and saved zoom offset; the real measured eye defines the warp UV. radius0 matches the existing centered native/legacy source math. Unsupported optional frontend/culling projections return no panel correction without latching the world prototype. Only an actual eligible World draw with a refused correction requests the flat session latch.

The device initially allocates640x480. Preparation waits for a compatible atlas size at an actual render-frame boundary, after requested MSAA preparation, and before World rendering. Copy texture/SRV are published together only after both exist; partial curve resources are released on preparation failure. Ready publication increments the shared correction revision so retained camera/culling planes and both backend correction caches refresh. Resource failure retains legacy projected views. Size changes revalidate source sampling/resources between frames or latch legacy. The latch is for this process; a refused correction is consumed after the current frame's world composite, then legacy flat-panel Angled applies next frame. The transition may have one experimental frame of differing coverage; it is not a promotion or an atomic mid-frame undo.

## World, fallbacks and final image

The logical back buffer remains the existing full-span source atlas, divided into3 viewport/depth regions. World XYZ/particles use widened source corrections; WorldCoverage darkening covers each source region. Ordinary world RHW and unmatched/custom world XYZ stay center-only, mapped into the original panel's inner source rectangle with native depth/order; they are not moved to a final overlay. The prototype suppresses HUD spacing for world-source RHW. Native viewport offsets are composed with that inner mapping, with source-clamped conservative scissor. Actual RHW appearance/position remains a rendered qualification item.

The geometry shader keeps its208-byte b0 correction layout. An optional48-byte b1 provides each source's inner X/Y scale. It scales both the reapplied D3D9 pixel-center fix and post-correction point-sprite extents; otherwise the widened source would alter point size/relative alignment after warping. fix.w advertises that contract. The ordinary path keeps unit scaling and a valid unused b1 binding; WorldCoverage keeps its prior identity constants. Actual shader execution is unqualified.

The existing MSAA resolve OR FXAA pass runs first, retaining their prior exclusivity. The compositor unbinds source SRVs/outputs, copies the completed world into a distinct sampling texture, unbinds the world GS, then draws3 mesh panels back into the final image. It uses its own pixel constant buffer and restores the native CB0 binding/cache state; its sampling SRV is unbound afterwards. Source depth/stencil is cleared before the final unwarped layer, matching the existing MSAA empty-depth contract. The42D710 hook, the first later non-world draw, or end_frame when no HUD appears completes the source once. HUD/frontend/late frontend XYZ follow unwarped. Reflections/offscreen target identity remains separate.

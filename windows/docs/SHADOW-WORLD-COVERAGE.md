# Angled stencil-shadow darkening coverage

The native `422740 -> 4220F0` pass draws the shadow object's RHW darkening strip with stencil LESS/ref0 and alpha blending. Its stencil volumes are a separate XYZ pass. Ordinary RHW takes the centered UI viewport in D3D11, so classifying all RHW as HUD leaves this world pass outside the three-view path.

Only that known draw, when called from `PcDrawPhase::World`, receives a scoped `WorldCoverage` phase. The caller phase is restored immediately after drawing, including a draw exception. HUD, frontend and unknown callers retain their phase. Offscreen targets remain excluded by the target check before coverage admission. The semantic domain remains WorldScreenEffect; no new domain-array index is introduced.

With Angled's correction callback installed, the D3D11 backbuffer route accepts that explicit RHW coverage. Three identity corrections use the existing triangle geometry shader to repeat the strip across the three world viewports without scene near-plane reprojection. Clip depth and pixel-center conventions remain unchanged. HUD spacing is disabled only for this admitted coverage; ordinary RHW, reflection targets and Off/Planar retain their current paths. Defaults, owner settings, object bytes, stencil/blend states and shadow-volume generation are unchanged.

Coverage replaces the shared three-view constant buffer, so it invalidates `triple_cached_`; the next ordinary XYZ draw reloads its actual projection correction even if that projection did not change. Existing per-projection cached entries are not replaced with identity. The exit diagnostic reports `explicit world-coverage draws into three viewports` separately from ordinary RHW fallbacks. A counter records submission, not rendered-pixel correctness.

`test_shadow_world_coverage` calls the actual native shadow function with a synthetic object and a recording subclass of the CPU software-state owner. It checks the full six-vertex packet, draw topology/FVF/stride, stencil and blend states at submission, texture-reference restoration, unchanged object/matrix data, caller phase restoration, absent-object behavior, draw-exception phase restoration, HUD/frontend/unknown/offscreen negative controls, identity constant packing, depth/pixel-center invariance and refusal without output mutation. Renderer reset constants come from the existing verified cache read-only through OR2_EXE; absent cache skips77. No GPU device is constructed.

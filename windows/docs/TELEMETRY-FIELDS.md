# Desktop telemetry field review — 2026-10-13

This review uses the clean `d480104` integration source, the Tweaks fork's 76-byte `OutRun2006TelemetryData` v1 contract, and the retained `artifacts/outrun-telemetry-30e3c31/listener/{packets,shared}.tsv` capture. That capture proves reception (1,904 Horizon packets and 110 shared-memory samples), not the physical meaning of each field. No new game, device or telemetry receiver run accompanied this source correction.
